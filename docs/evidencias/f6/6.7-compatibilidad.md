| Firefox | **reserva** | No hay forma de controlarlo desde el entorno (motor Gecko distinto: `AbortSignal.any`, `OffscreenCanvas` solo en el script de medida, CSS `min()`, `<details>` y rejillas con `minmax(min(…))` están en Firefox >= 124 / 2024) |
| Safari / iOS | **reserva** | No disponible. `AbortSignal.any` (usado por el cliente de la API) exige Safari >= 17.4 (marzo 2024); versiones anteriores no abrirían el panel con la API |
| Dispositivo físico (móvil) | **reserva (T047)** | Se probará con la URL de Netlify desde otro dispositivo cuando se autorice la publicación (PA-8) |

Funciones del navegador que usa el panel y su disponibilidad, para la reserva: `fetch` con `AbortSignal.timeout` y `AbortSignal.any`, CSS `min()` / `minmax()` / rejillas / `:focus-visible`, `<details>`, `Intl.NumberFormat('es-ES')`, `performance.now`, `document.visibilityState`. No usa nada experimental ni prefijos. Los navegadores sin `AbortSignal.any` (Chrome < 116, Firefox < 124, Safari < 17.4) quedan fuera de soporte; Angular 20 ya exige navegadores recientes.
